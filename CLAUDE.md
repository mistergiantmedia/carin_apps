# carin_apps (alle apps in deze repo)

**Altijd naar `main` pushen als je klaar bent** (`git push origin HEAD:main`). Een push naar `main` deployt via
`webhook/deployer.php`; een andere branch doet niets. Vraag er niet eerst om: de eigenaar wil dit altijd, voor elke app
in deze repo (familyplanner, jouwschoolplein, …). Geldt ook als een sessie een eigen werkbranch voorschrijft: push daar
én naar `main` (fast-forward; haal eerst `origin/main` op en merge als die vooruit is gelopen).
Maak geen pull request tenzij erom gevraagd wordt.

Elke app heeft zijn eigen CLAUDE.md (bijv. `familyplanner/CLAUDE.md`).
